
variables
=========

Variables are used to store data values. They are created by simply assigning a value to a name (identifier) using the = operator.

x = 10          
name = "Alice"  
pi = 3.14       
is_active = True  


data types
=========

1. Numeric Types
----------------
int: Integer numbers (whole numbers) without a decimal point.
Example: x = 5, y = -42
float: Floating-point numbers (numbers with a decimal point).
Example: x = 3.14, y = -0.99

2. Text Type
------------
str: String, used to store sequences of characters (text).
Example: name = "Alice", greeting = 'Hello, World!'

3. Boolean Type
---------------
bool: A data type that can have one of two values: True or False.
Example: is_active = True, has_permission = False


conditionals
==============
conditionals are used to execute specific blocks of code based on whether a condition is True or False. 
The primary conditional statements are if, elif, and else

age = 20

if age >= 18:
    print("You are an adult.")
elif age >= 13:
    print("You are a teenager.")
else:
    print("You are a child.")


Loops
======
Loops are used to iterate over a sequence (like a list, tuple, or string) or to repeat a block of code multiple times. 
There are two primary types of loops in Python: the for loop and the while loop.

for 
---
fruits = ['apple', 'banana', 'cherry']
for fruit in fruits:
    print(fruit)

while
-----
i = 0
while i <= 10:
    print(i)
    i += 1  # Increment i after each iteration

execptions
===========
exceptions are events that can modify the flow of control through a program. 
They are usually caused by errors that occur during the execution of the program, such as trying to divide by zero, 
accessing an index that doesn't exist in a list, or opening a file that doesn't exist.

try:
    # Code that might cause an exception
    x = 1 / 0  # This will cause a ZeroDivisionError
except ZeroDivisionError:
    # This block is executed if a ZeroDivisionError occurs
    print("Cannot divide by zero!")

lists, tuples, sets,Dictionaries
================================
list
-----
list is an ordered collection of items that can be changed (mutable), and the items can be of different types.

my_list = [1, 2, 3, 'apple', 4.5]

tuple
-----
A tuple is very similar to a list, but it is immutable (cannot be changed after creation).

my_tuple = (1, 2, 3, 'banana', 4.5)

set
---

A set is an unordered collection of unique items. It is mutable and does not allow duplicates.

my_set = {1, 2, 3, 'orange'}


dictionary
----------
A dictionary is a collection of key-value pairs, where each key is unique and maps to a specific value. It is unordered, mutable, and indexed by keys.

my_dict = {'name': 'John', 'age': 25, 'city': 'New York'}


functions
========
functions are blocks of reusable code that perform a specific task.
